##Where A Small Language Model Helps in Invoice Categorisation, Understood Through Embedding Geometry

This repository contains the code to produce the analysis for the paper “Where A Small Language Model Helps in Invoice Categorisation,Understood Through Embedding Geometry”. The author of this repository is Emma Ceccherini (emma.ceccherini@bristol.ac.uk). This work was performed while on an internship at System Holding, under the supervision of Dr Daniel Lawson and Dr Anjulika Salhan.

##Data

The data used for this analysis is confidential and the property of System Holding. A small part of the code is also omitted to protect System Holding's IP.

##AI usage

This project was developed by Emma Ceccherini with the assistance of Claude Opus 4.8 by Anthropic. AI was used as a coding aid throughout development; all design decisions are those of the authors, and all final code has been thoroughly reviewed.
